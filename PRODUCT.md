# Badgecraft
<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Implementation choice delegated by the request to select and build an appropriate application. Buildless HTML, CSS, and JavaScript modules suit a purely client-side playground; Sites hosts the static output.

## Users and purpose
Discord enthusiasts discovering evolving badges and experimenting with simulated profiles without connecting an account.

## Capabilities and constraints
Four badge galleries, tier explorer, editable profile preview, FAQ, and a merged six-step community-script guide with the existing code editor. Website interactions remain client-side: no credential collection, Discord API calls, account actions, or script execution. The provided Python source is offered unchanged for review, copy, and download; it requires credentials and makes authenticated requests when a visitor independently runs it locally. Plaintext credential storage, Windows-only fingerprinting, Discord policy risks, and unverified effectiveness must be clear. Official badge mechanics and community-documented tiers remain visibly distinguished.

## Brand commitments
Premium gaming aesthetic, midnight charcoal, Discord blurple, purple/blue/cyan lighting, tasteful animation, responsive layouts, keyboard access, reduced-motion support. Badgecraft is a replaceable temporary name. Independent of Discord.

## Featured community profile
The user authorized a hero adaptation of their supplied UnkindledOne profile: a golden sunset, dark-haired avatar with an autumn decoration and black cat companion, amber display name, exclusive.mizzy handle, Oblivion tag, Japanese status, and DND indicator. Generated illustration assets support native HTML interactions. This featured identity stays separate from the existing “A profile that feels like you” playground, which visitors can still customize. Featured badges are stylistic previews, not a live account readout.

## Evidence
Official Discord support articles checked October 27, 2026. Tier names and thresholds from EliteZilla/Discord-Badges, cross-checked against Infinity Hub's published tier list. Discord badge artwork mirrored by dev-hoehle/discord-badges, attributed in the site and source notes.
